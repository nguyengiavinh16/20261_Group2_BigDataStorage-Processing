# data/raw – dữ liệu PaySim gốc

Đặt file PaySim gốc (CSV, khoảng 470 MB, khoảng 6,36 triệu dòng) vào thư mục này.
Nguồn: Kaggle `ealaxi/paysim1`.

Cách 1: chạy `python3 download_paysim.py` từ thư mục gốc của gói (cần `pip install kagglehub`).
Cách 2: tải thủ công từ https://www.kaggle.com/datasets/ealaxi/paysim1 và copy file CSV vào đây.

Thư mục này không chứa dữ liệu trong gói. File gốc không được commit vào git.
