# Eight-week roadmap
1. Foundation, data inspection, configs, logging, unit tests.
2. Data ingestion, CSV-to-Parquet, Spark ETL, Kafka replay producer.
3. Baseline model training, thresholded metrics, artifact persistence.
4. Kafka + Spark Structured Streaming scoring and MongoDB sink.
5. FastAPI prediction endpoint and Streamlit UI.
6. Basic latency/error benchmark, tests, operational failure review.
7. Docker Compose for API, dashboard, MongoDB, Kafka; Kubernetes starter manifests.
8. Integration validation, reproducible evaluation, architecture and results report.

Milestones are implementation targets, not claims that external infrastructure has been provisioned or tested. See `implementation_guide_vi.md` for commands and known limitations.
