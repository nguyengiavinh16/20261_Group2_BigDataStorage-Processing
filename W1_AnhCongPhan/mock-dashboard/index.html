Metric definitions

  • Transactions scored: number of documents in predictions whose scored_at falls in the selected range.
  • Alert: fraud_score ≥ alert_threshold (provisionally 0.5). HIGH when ≥ 0.8.
  • Latency: scored_at − produced_at. End-to-end latency through Kafka and Spark, excluding the DB write.
  • DLQ: messages that fail to parse or violate the schema (including messages that contain isFraud).
  • event_time: simulated time derived from PaySim's step, not real wall-clock time.

Intentionally not shown

  • Real-time precision / recall: ground-truth labels are kept out of the scoring path. Thái evaluates offline by joining on transaction_id.
  • "Fraud probability %": fraud_score has not been checked for calibration.
  • Throughput / consumer lag: to be added in W7 once measurement tooling is in place. Unmeasured numbers are not displayed.
